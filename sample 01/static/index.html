Frequently Asked Questions

Does a 100/100 score mean a website is completely unhackable?

No. A 100/100 score means the public homepage observes all recommended modern defensive headers, strict TLS encryption, and has no reported phishing listing. However, underlying application vulnerabilities (such as SQL injection or authentication flaws) cannot and should not be tested via passive scanning.

Why does missing a single header matter?

Security operates on defense-in-depth. For instance, without Strict-Transport-Security (HSTS), attackers on public Wi-Fi can downgrade users to unencrypted HTTP. Without Content-Security-Policy (CSP), cross-site scripting (XSS) attacks can steal user tokens.

Can I safely check any public website?

Yes, passive observation only views the public headers sent to any standard web browser. However, as standard ethical security practice, we recommend auditing your own domains or systems you have authorization to assess.
